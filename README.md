# Mystical 🎮✨

Mystical is a native-inspired desktop app that unifies all your games—across Steam, Epic Games, GOG Galaxy, EA App, Minecraft, and Roblox—into one elegant, theme-aware interface.

## Features

- 🔍 Automatic game detection via local manifests & APIs
- 🎨 Fluent UI-inspired design (accent pills, translucent cards, theme switcher)
- 🚀 Launch games directly from within the app
- 🧠 Categorize and filter by platform or genre
- 🕹️ Creator’s Choice highlights for your favorites
- 🔄 Background syncing of metadata and library changes

## Tech Stack

- **Electron**: Cross-platform desktop shell
- **React** or **Vanilla JS**: For dynamic UI rendering
- **Tailwind CSS** / **Fluent UI**: Styling with native polish
- **Node.js**: Backend sync logic and local file parsing
- **SQLite / JSON**: Local lightweight storage of game data
